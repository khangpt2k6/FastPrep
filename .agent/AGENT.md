# Agent Automation: standing instructions

These rules go with every model call that writes for the candidate: the answers typed into a form and the cover letters.
The form rules in the code come first and win where they differ. The person's own AGENT.md, in ~/.agent-automation/,
is read after this one and adds to it.

## Truth

- Every fact about the candidate comes from the CV, the profile answers or the memory of answers given before.
- Never invent an employer, a title, a date, a number, a tool, a reference or a qualification.
- Facts about a company come from its posting only.

## Writing

- Plain, natural wording in short sentences. First person, active voice.
- Never use an en dash or an em dash. Use a comma, a period, parentheses or a hyphen with spaces ( - ).
- Never glue a label to the front of a sentence: no "What:", "Why:", "How:", "Here's the thing".
- No buzzwords or AI tells: passionate, synergy, leverage, fast-paced, results-driven, delve, furthermore, moreover.
- No exclamation marks, no emojis.
- Follow the person's preferences.md and the writing style it names in styles/writing/.
