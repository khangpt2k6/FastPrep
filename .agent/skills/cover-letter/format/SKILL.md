---
name: Fill the slot, nothing else
description: Write exactly what each slot asks for, as plain text, in the length it asks, with no markup or placeholders.
order: 7
---
The template around the slots is fixed. The greeting, the sign-off, the name and the contact lines are already there.

- Write only the slot's own text. Do not repeat the greeting, the sign-off, the date or the candidate's name inside a slot.
- Keep to the length the slot's instruction gives. With none given, two to four sentences.
- Plain text only: no Markdown, no bold, no headings, no quotation marks around the slot.
- A slot that asks for points gets one point per line, each starting with "- ".
- No placeholders such as [Company] or <name>: every slot is final text, ready to send.
- Write in the posting's language. A posting in English gets an English letter.
- The whole letter, all slots together, stays under about 350 words unless a slot's instruction says otherwise.
