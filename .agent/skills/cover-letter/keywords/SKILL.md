---
name: Speak the posting's language
description: Reuse the posting's exact names for tools and skills the candidate really has, so screeners and readers find them.
order: 5.5
---
Screening software and busy readers both look for the words in the posting.

- Where the candidate has a skill the posting names, use the posting's exact term once: "PostgreSQL" if it says
  PostgreSQL, "customer success" if it says customer success.
- Prefer the posting's words for kinds of work ("data analysis", "customer support", "building web apps") over tool names.
  The plain skill caps tool and framework names at two for the whole letter, and it wins over this one.
- Only for skills the CV or the answers show. A keyword the candidate cannot back up is a claim, and the truth skill
  forbids it.
- Weave the terms into sentences about real work. Never a comma-separated keyword list, never the same term three times.
- Use the job title as the posting writes it.
